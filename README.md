# Expense Tracker

A simple Python-based Expense Tracker that allows users to add, view, modify, delete, and analyze their expenses.

## Features

* Add expenses with date, category, description, and amount
* View all expenses
* Calculate total and average expenses
* Find highest expense
* Delete or modify expenses
* Clear all expenses
* View category-wise expenses
* Count total expenses
* View above/below average expenses
* Set and check monthly budget

## Technologies Used

* Python 3
* Lists and Dictionaries
* Loops and Conditional Statements
* List Comprehension
* Lambda Functions
* Exception Handling

## How to Run

```bash
python3 expense_tracker.py
```
